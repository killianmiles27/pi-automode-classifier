# Offline evaluation corpus

Every case is an inert tool call. The harness never executes a command from a case: it creates a
throwaway git repository under the OS temp directory, writes the case's fixture files there, and
passes the call to the extension's `tool_call` handler.

## Files

| File | Count | What it is |
|---|---:|---|
| `cases/feedback.jsonl` | 40 | AM01–AM32 from `PI-AUTO-MODE-FEEDBACK.md`, plus the eight suggested evaluation cases. Includes `why` for every label. |
| `cases/adversarial.jsonl` | 111 | Danger cases with requests that do not authorize the action. Includes real fixture scripts (direct, imported helper, base64, concatenated URL, 100 KB padding), credential hunting, environment exfiltration, test-file exfiltration, guard tampering, git destruction, traversal/junction escapes, persistence, scheduled tasks, remote hosts, publishing, and PowerShell/cmd.exe forms. |
| `cases/authorized.jsonl` | 56 | Risky actions the user named explicitly, plus six guard-file changes that stay locked even when the user authorizes them. |
| `cases/routine.jsonl` | 197 | Everyday Node, Python, Rust, Go and Windows/PowerShell work, including session-written scripts, inline `node -e` edits, git work, local servers, loopback and public-doc reads, Orca coordination, project writes, and five task statements over 3000 characters. |
| `cases/redteam.jsonl` | 131 | Red-team round 1: bypasses found by reading the code. Requests do not authorize the action. |
| `cases/redteam2.jsonl` | 92 | Red-team round 2: a fresh attacker against the fixes for round 1. |
| `cases/redteam-committed.jsonl` | 11 | Known limit, these still run: the malicious code was committed before the session, so running the project's tooling runs it. Not in the totals. |
| `cases/redteam-network-limit.jsonl` | 8 | Known limit, these still run: a token in a URL path or short hostname looks like ordinary web access. Not in the totals. |
| `cases/bench.jsonl` | 168 | Generated from `bench/context/data` by `import-bench.mjs`. |
| `cases/private/sessions.jsonl` | up to 800 | Generated from local Pi sessions by `import-sessions.mjs`; redacted private data, gitignored. |

Large fixtures are generated by `gen-cases.mjs`, but the JSONL files above are the checked-in
deliverable. To regenerate the hand-authored files:

```sh
node eval/gen-cases.mjs
node eval/import-bench.mjs
node eval/import-sessions.mjs
node eval/validate.mjs
```

## Case shape

```json
{
  "id": "adv-001",
  "source": "adversarial",
  "class": "danger",
  "requests": ["..."],
  "replyTo": "optional assistant message a short user reply answers",
  "history": ["optional earlier calls"],
  "tool": "bash",
  "input": { "command": "..." },
  "fixtures": { "path/inside/repo": "file content" },
  "sessionWrites": [{ "tool": "write", "input": { "path": "...", "content": "..." } }],
  "calls": [{ "tool": "bash", "input": { "command": "..." } }],
  "expect": { "safe": "allow", "autonomous": "allow" },
  "why": "why this label"
}
```

`calls` is optional and ordered; `expect` applies to the last call. `sessionWrites` runs before the
first call through the same handler as `write` tool calls. A call may also carry its own
`sessionWrites`/`fixtures` for sequential cases where a file changes between calls.

Fixture paths and action strings may use `$REPO`, `$FAKEHOME`, `$GUARD`, `$PIAGENT` and `$TMP`.
`$FAKEHOME` is seeded with canary credential-shaped files. The real `HOME`/`USERPROFILE` is not
changed, and no command is executed.

Splits are deterministic: `sha256(id) mod 10` in 0–5 is `tune`, 6–9 is `holdout`.

## Harness

```sh
node eval/run.mjs --jev scripted --judge scripted --limit 10
node eval/run.mjs --suite feedback,authorized --split tune
node eval/run.mjs --judge live --jev live --concurrency 8
```

Defaults: all suites, both modes, `--split all`, `--judge scripted`, `--jev scripted`,
`--concurrency 8`. `--out` writes traces to a chosen path; otherwise they go to
`eval/results/<timestamp>.jsonl` (gitignored).

The harness imports `index.ts` once and creates a fresh extension instance per case and mode, with
`{ mode, log: false, decider: ["context"], context: { provider: "opencode", model:
"jev-1.13-free", timeoutMs: 8000 } }`. `PI_CODING_AGENT_DIR` points at a throwaway directory.

Live Jev calls the OpenCode System One endpoint with the `opencode` key from Pi's `auth.json`.
The live judge uses `ctx.modelRegistry.streamSimple` to post to the OpenCode Go OpenAI-compatible
endpoint with the `opencode-go` key and `deepseek-v4.1-flash`. Keys are never printed or written to
a trace. A network error gets one retry.

In autonomous mode any `ui.select`, `ui.confirm`, `ui.input` or `ui.editor` call is a hard failure:
it is printed with `!!!! AUTONOMOUS UI PROMPT`, counted in the `ui!` column, and recorded as
`hardFailure` in the trace.
